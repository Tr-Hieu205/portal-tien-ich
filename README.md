# Tr_Hiuz ✨ // Kho Tiện Ích Cá Nhân & Công Cụ Tự Động Hóa

Trang web tổng hợp các tiện ích mở rộng trình duyệt (Chrome MV3) và công cụ tối ưu trải nghiệm duyệt web, bảo mật và tự động hóa cá nhân của **Tr_Hiuz** (Nguyễn Trung Hiếu).

---

## 🌟 Danh Mục Tiện Ích

### 1. ⚡ Facebook Toolkit Pro (Manifest V3)
*Bộ tiện ích tự động hóa & bảo mật Facebook toàn diện:*
- **Lọc bạn bè & Tương tác:** Quét bạn bè lâu ngày không tương tác, hủy kết bạn tự động theo token-bucket an toàn, tự động chọc (poke) hoặc thả tim/haha story hàng loạt.
- **Dọn dẹp trang cá nhân:** Ẩn hoặc xóa hàng loạt bài viết cũ, ảnh cũ, bình luận cũ theo từ khóa hoặc khoảng thời gian.
- **Tải media & Sao lưu dữ liệu:** Tải toàn bộ ảnh trong album thành file nén ZIP, trích xuất link video HD/SD, xuất danh sách bạn bè/tin nhắn định dạng JSON/CSV an toàn chống formula injection.
- **Bảo mật & Tiện ích ẩn:** Bật khiên bảo vệ ảnh đại diện (Avatar Guard), chặn trạng thái "Đã xem" (Seen) khi đọc tin nhắn Messenger, chặn thông báo "Đang nhập..." (Typing).
- **Chúc mừng sinh nhật Messenger (Danh sách chọn):** Tự động gửi tin nhắn Messenger riêng tư chúc mừng sinh nhật cho danh sách bạn bè được chọn trước (Whitelist), tuyệt đối **không** tự ý đăng bài lên tường/dòng thời gian.

### 2. 🌸 CuteTube Personalizer (Manifest V3)
- Biến toàn bộ giao diện YouTube sang Dark Pastel dịu mắt (Sakura, Mint, Peach, Lavender).
- Đồng hành cùng 3 thú cưng mini kéo thả tự do (Mèo Mochi, Thỏ Bông, Gấu Kem).
- Thanh tua video gradient trái tim và tự động bỏ qua quảng cáo YouTube.

### 3. 🛡️ AdShield Pro (Manifest V3)
- Chặn quảng cáo cấp trình duyệt với Cosmetic Filtering CSS ẩn sạch phần tử banner và popup.
- Tiêm Scriptlet vô hiệu hóa anti-adblock và tua nhanh quảng cáo video.
- Tùy chỉnh danh sách Whitelist / Blacklist linh hoạt.

### 4. 🌐 DNS Guardian Server (RFC 1035 UDP)
- Hệ thống máy chủ DNS riêng biệt viết bằng Node.js / TypeScript.
- Bộ nhớ đệm TTL RAM phân giải dưới 1ms, lọc chặn tên miền quảng cáo qua EasyList Trie (>8 triệu lượt/giây).
- Đi kèm file cấu hình di động `.mobileconfig` cho iOS / macOS.

## 🚀 Hướng Dẫn Cài Đặt Nhanh Vào Chrome (1-Chạm)
1. Tải file cài đặt `.bat` tương ứng (ví dụ: `Cai_Dat_Facebook_Toolkit.bat`, `Cai_Dat_CuteTube.bat`, `Cai_Dat_AdShield.bat`).
2. Nhấp đúp chuột vào file `.bat`: Trình duyệt Chrome sẽ tự động mở trang `chrome://extensions` kèm thư mục tiện ích.
3. Bật **Chế độ dành cho nhà phát triển (Developer mode)** ở góc trên bên phải Chrome.
4. Kéo thả thư mục tiện ích vừa hiện lên vào giữa màn hình Chrome để sử dụng ngay lập tức!
